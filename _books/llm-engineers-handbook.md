A comprehensive engineering guide covering the full LLM development lifecycle: data collection, fine-tuning, alignment, inference optimisation, RAG pipelines, and MLOps. Iusztin and Labonne write from genuine production experience and the result is a book that treats engineering rigour with the same seriousness as model quality. Particularly useful for the deployment chapters — understanding how to set up efficient serving pipelines complements research work on model behaviour.
